# YK 에듀테크 강의 요청 홈페이지

YKEDUTECH GitHub 계정의 `home` 저장소에 게시하기 위한 정적 홈페이지입니다.

## 폴더 둘러보기

- `index.html`: 홈페이지 첫 화면
- `pages/programs.html`: 강의 분야와 프로그램
- `pages/instructor.html`: 강사 소개와 이력
- `pages/request.html`: 강의 요청 양식
- `assets/css/`, `assets/js/`: 공통 디자인과 기능
- `docs/`: 제작 기준, 사용법, 배포 안내
- `.github/workflows/pages.yml`: GitHub Pages 자동 배포

## 시작하기

먼저 [docs/사용안내.md](docs/사용안내.md)에서 이메일과 강사 정보를 설정하고, [docs/GitHub-Pages-배포.md](docs/GitHub-Pages-배포.md)의 절차에 따라 `https://github.com/YKEDUTECH/home` 저장소에 올리세요.

강의 요청 양식은 현재 방문자의 이메일 프로그램을 열어 입력 내용을 전달합니다. 별도의 서버 없이 작동하지만, 제출자의 기기에 이메일 프로그램이 설정되어 있어야 합니다. 실제 자동 접수가 필요하면 별도 폼 서비스나 서버 연동이 필요합니다.
