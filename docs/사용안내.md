# 홈페이지 사용 안내

## 강의 요청을 받을 이메일 설정

`assets/js/main.js`를 열고 다음 줄의 주소를 실제 강의 문의 수신 주소로 바꿉니다.

```js
const recipient = 'CHANGE-ME@example.com';
```

예를 들어 `const recipient = 'hello@example.kr';`처럼 바꿉니다. 주소를 설정하기 전에는 양식이 전송되지 않고 안내 문구를 보여줍니다. 이 방식은 방문자의 이메일 앱을 실행하므로 모바일·PC에 메일 앱이 설정되어 있어야 합니다.

## 강사 소개 편집

`pages/instructor.html`을 열어 `[강사 이름]`, `[전문 분야 1]`, `[연도]`처럼 대괄호로 표시된 부분을 공개 가능한 실제 정보로 교체합니다. 기존 [Google Sites 강사 자료](https://sites.google.com/view/yk-edutech/)를 확인해 정확하게 옮기세요.

## 강의 과정 편집

`pages/programs.html`의 강의명, 대상, 교육 내용을 실제 제공 가능한 과정으로 수정합니다. 현재 내용은 기본 예시이므로 실제 서비스 여부를 확인한 다음 게시하세요.

## 사이트 이름과 문구 편집

페이지 하단의 `YK EDUTECH`, 브라우저 탭 제목, 소개 문구를 필요에 맞게 수정합니다. 색과 레이아웃은 `assets/css/style.css`에서 바꿉니다.

## 실제 접수 서비스로 바꾸기

메일 앱을 거치지 않고 홈페이지에서 바로 접수하려면 폼 처리 서비스를 연결해야 합니다. 서비스가 정해지면 `pages/request.html`의 제출 주소/연동 코드를 설정하고, 개인정보 수집 항목·보관 기간·처리 방침을 그 서비스 방식에 맞춰 안내합니다. 비밀번호나 서비스 비밀 키를 HTML/JavaScript에 넣지 마세요.
