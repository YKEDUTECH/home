# 홈페이지 제작 기획

## 목적

YK 에듀테크의 강의 분야와 강사 정보를 소개하고, 기관 담당자가 교육 상담을 요청할 수 있는 홈페이지를 만든다.

## 참고 자료

- [COALAB](https://coalab.co.kr/): 첫 화면의 핵심 메시지, 교육 분야별 소개, 문의 동선, 현장 신뢰 정보를 참고했다. 디자인과 문구를 복사하지 않고 별도 구성으로 제작했다.
- [YK 에듀테크 Google Sites](https://sites.google.com/view/yk-edutech/): 기존 강사 소개와 교육 자료를 확인할 출처로 연결했다. 자동 열람이 되지 않아 이력·실적은 추측해 기재하지 않았으며 `pages/instructor.html`에서 실제 내용을 입력하도록 했다.
- [GitHub 저장소](https://github.com/YKEDUTECH/home): 게시 대상 저장소로 안내했다.

## 화면 구성

1. 홈: 교육 제안, 대표 강의 분야, 진행 절차, 문의 버튼
2. 강의 분야: 디지털·AI, 데이터, 기관 맞춤 교육의 소개
3. 강사 소개: 프로필, 전문 분야, 강의 경력, 자격·저술
4. 강의 요청: 담당자와 기관 연락처, 희망 분야·일정, 상세 문의

## 기술 구성

HTML, CSS, 바닐라 JavaScript로 만든 정적 사이트다. 빌드 도구나 패키지 설치 없이 GitHub Pages에서 제공할 수 있다. 모든 페이지에서 상대 경로를 사용해 `home` 저장소 하위 경로에서도 링크가 작동하도록 구성했다.

## 문의 양식의 현재 동작

입력값을 브라우저에서 `mailto:` 링크로 이메일 프로그램에 넘긴다. 웹사이트 서버에 입력값을 저장하거나 전송하지 않는다. 자동 이메일 접수, 접수 내역 관리가 필요하면 Formspree, Google Forms 등 외부 폼 서비스 또는 별도 백엔드를 연결해야 한다. 서비스 선택 후 개인정보 처리 안내도 해당 방식에 맞게 고쳐야 한다.

## 공개 전 편집 항목

- `assets/js/main.js`의 받는 이메일 주소
- `pages/instructor.html`의 대괄호 프로필·이력
- `pages/programs.html`의 실제 제공 과정과 대상
- 연락처, 개인정보 처리 안내, 실제 운영 정보
- 강의 분야 예시가 실제 서비스와 맞는지 확인
